# Toy IP 3D

一个用于 Codex 的 Skill：从角色原画建立可复用的 3D 潮玩图片母版与角色身份卡，再以母版制作换装、姿势和表情变体。

它生成的是 **3D 风格图片**，不是可旋转、可打印的三维模型。仓库包含通用 Skill、空白身份卡模板，以及 Pinky 的原画、已确认 3D 母版与角色身份卡作为使用示例。

## 安装

把本仓库克隆到 Codex 的个人 Skills 目录：

```bash
git clone https://github.com/vivilin826/toy-ip-3d.git ~/.codex/skills/toy-ip-3d
```

重新打开 Codex 后，可在对话中提及 `$toy-ip-3d`，并提供角色原画或已有的 3D 母版。

已经安装过本仓库时，在 Skill 目录执行 `git pull` 更新即可。Pinky 示例文件位于 [examples/pinky/](examples/pinky/)。

## 使用方式

- 首次建立角色：附上原画，让 Codex 生成 3D 母版及角色身份卡。
- 制作系列变体：附上已确认的母版，或让 Codex 从当前项目读取母版与身份卡，再描述服饰、姿势、表情或场景；也可以附参考图并指定各图的用途。
- 母版固定角色身份与五官结构，表情可变。外部人物参考图只影响用户指定的部分。

### 可以直接发送的简短指令

首次建角色，附上原画：

> `$toy-ip-3d 把这张原画做成 3D 潮玩母版，并建立角色身份卡。`

用自己的角色换装，附上服饰参考图：

> `$toy-ip-3d 用 Pinky 母版换成这张图的衣服。脸、发色和红白波点发夹不变；姿势用参考图，白底。`

没有参考图，也可以只描述衣服：

> `$toy-ip-3d Pinky 换黄色运动上衣和蓝色短裤，沿用母版姿势，闭眼笑，白底。`

如果只想改变表情：

> `$toy-ip-3d 这一版只改成俏皮眨眼，服饰、姿势和人物五官不变。`

指令可继续缩短成“Pinky 换这套衣服，其他不变”，前提是 Codex 能读取当前项目的母版和角色身份卡。附参考图时，最好明确它负责**服饰、姿势还是表情**；不指定姿势时，Skill 默认沿用母版姿势。

具体工作规则见 [SKILL.md](SKILL.md)，空白身份卡见 [references/character-card-template.md](references/character-card-template.md)。
